# Identifier families from a retired issue-tracking scheme. They resolve to
# nothing, so a citation is a dead reference: state the rationale inline, or
# cite an ADR under docs/adr/. [a-z]? covers suffixed variants (FR-001a);
# (?-i:) keeps matching uppercase-only — these IDs were always uppercase, and a
# case-insensitive T\d{3} would false-positive on base64 blobs (go.sum, key
# material):
re:(?-i:\bFR-\d+[a-z]?\b)
re:(?-i:\bT\d{3}[a-z]?\b)
re:(?-i:\bSC-\d+[a-z]?\b)
re:(?-i:\bNFR-\d+[a-z]?\b)
