# configuration and instruction files. These are developer-local settings, not
# project source. Committing them publishes one contributor's local tooling
# setup into a tree every contributor shares, and they drift silently because
# nothing builds or tests them. Keep them in your own ignore file instead
# (git supports a machine-global one via core.excludesFile).
#

#   name/   directory; matches when any path segment equals it, at any depth
#   name*   filename prefix; matches when the basename starts with it
#   name    filename; matches when the basename equals it, at any depth
